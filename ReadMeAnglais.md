# Project "Hunger Games"

## Objective

Create a board game directory website to allow users to find a game suited to their preferences.

## Targeted Skills

### Building Static Web or Mobile Web User Interfaces

- **Skills** : Web page development using HTML5, CSS3, understanding of responsive layout.
- **Example** : Coding in HTML5 and CSS3 to structure web pages and apply styles.

### Developing Dynamic Web or Mobile Web User Interfaces

- **Skills** : JavaScript programming to enhance user interaction.
- **Example** : Using JavaScript to make interfaces interactive.

### Retrieving, Storing and Redistributing Data from a Database

- **skills** : SQL programming to retrieve data and PHP to store and redistribute it.
- **example** : Using SQL to write queries for data retrieval.
Using PHP to store and redistribute data.

## Features

- Search games by category
- Sort by game type
- Details page with rating, number of players, duration, category and description
- User login
- Add to favourites
- Admin login
- Management of games, users and categories

## Technologies Used

- HTML5 (semantic tags)
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (interactivity)
- SQL (database queries)
- PHP (server-side)

## Design

- **User** :

- Index : Game listing with categories
- Games : Details of the game selected by the user
- Register : Ability to sign up using a form
- Login : User profile
- Favourites : Ability to add a favourites list

- **Administrator** :

- Dashboard : Admin home page
- Login : Sign in
- Logout : Sign out
- Games : CRUD for game management
- Users : User management
- Categories : Category management
